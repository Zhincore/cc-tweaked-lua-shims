# ComputerCraft: Tweaked Type Definitions

Typed Lua definition files (`.d.lua`) for ComputerCraft: Tweaked APIs, providing autocomplete and type checking for Lua language servers.

## About

These type definitions were generated by **Claude Sonnet 4.5** based on the [CC: Tweaked](https://github.com/cc-tweaked/CC-Tweaked) API documentation, specifically for commit [`06d1abe`](https://github.com/cc-tweaked/CC-Tweaked/tree/06d1abfeca2d0028663b2aa044e901111565efb6).

## Documentation

For complete API documentation, see the official [CC: Tweaked documentation](https://tweaked.cc/).

## Files

- **`cc.d.lua`** - Core ComputerCraft APIs
  - `os`, `term`, `colors/colours`, `fs`, `peripheral`, `redstone/rs`
  - `rednet`, `http`, `textutils`, `settings`, `gps`, `help`
  - `disk`, `paintutils`, `parallel`, `vector`, `keys`, `window`
  - `io`, `shell`, `multishell`
  - Global functions: `print`, `write`, `read`, `loadfile`, `dofile`

- **`turtle.d.lua`** - Turtle API
  - Movement: `forward`, `back`, `up`, `down`, `turnLeft`, `turnRight`
  - Interaction: `dig`, `place`, `attack`, `suck`, `drop`
  - Inspection: `detect`, `inspect`, `compare`
  - Inventory: `select`, `getItemDetail`, `transferTo`, `craft`
  - Native functions: `turtle.native.*`

- **`peripherals.d.lua`** - Peripheral types
  - `Monitor`, `Modem`, `Speaker`, `Printer`, `Drive`
  - `Computer`, `CommandBlock`, `Inventory`
  - `EnergyStorage`, `FluidStorage`, `Workbench`
  - Advanced Peripherals: `NeuralInterface`, `ChatBox`

- **`pocket.d.lua`** - Pocket Computer API
  - `equipBack`, `unequipBack`, `getFuelLevel`, `refuel`

- **`commands.d.lua`** - Command Computer API
  - `exec`, `execAsync`, `list`, `getBlockPosition`, `getBlockInfo`

- **`cc-modules.d.lua`** - CC: Tweaked modules
  - `cc.audio.dfpwm` - DFPWM audio encoding/decoding
  - `cc.completion` - Input completion helpers
  - `cc.expect` - Argument type checking
  - `cc.image.nft` - NFT image format support
  - `cc.pretty` - Pretty printing
  - `cc.require` - Module loading system
  - `cc.shell.completion` - Shell completion utilities
  - `cc.strings` - String manipulation utilities

## Usage

These files provide type hints for Lua Language Server (LuaLS). Simply place them in your project's `lib` folder and configure your LSP to recognize them.

For LuaLS, add to your `.luarc.json`:
```json
{
  "workspace.library": ["lib"]
}
```
